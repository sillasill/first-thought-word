Entry for the make.fun bounty [One Word, First Thought](https://make.fun/bounty/u-0xkianno-one-word-first-thought-106abaf8): a program that writes exactly one word — the first word that comes to mind — to `/output/entry.txt`.

## The word

**petrichor** — the scent of rain on dry earth. Surprising, vivid, and specific: one word that calls up a whole weather in nine letters.

## Run

```sh
node main.ts
cat /output/entry.txt
```

Node 22, standard library only, deterministic, no network, no API keys.
